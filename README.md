# Filira Cosmetics: novo visual

Modelo da nova página inicial da loja [filiracosmetics.com.br](https://www.filiracosmetics.com.br), seguindo a identidade do Instagram [@filiracosmetics](https://instagram.com/filiracosmetics).

## Como ver

Abra o arquivo `index.html` no navegador (dois cliques). As imagens de prévia ficam em `previa/`.

## O que tem aqui

- `index.html`: a página completa (visual, textos e produtos)
- `img/png/`: fotos dos produtos recortadas, sem fundo
- `img/`: fotos originais tiradas da loja
- `previa/`: imagens de como a página fica no PC e no celular
